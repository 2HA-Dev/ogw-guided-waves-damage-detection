## What the validation showed before the test

- Original validation (38 to 42 °C band, positions already seen): AUC 1.000 on all splits, hence **saturated**, unusable for tuning anything.
- Nested validation (one training position held out, the external test set left out): first version biased (healthy validation measurements all in a temperature band absent from training, hence AUCs inverted down to 0.06); corrected (healthy validation = cooling ramp of cycle 1, same temperatures as training).
- Corrected nested validation, mean AUC over 12 folds × 5 seeds: base configuration 0.644, regularized configuration 0.647. Regularization does not help: base configuration kept.
- PCA: k chosen per fold on the validation set (healthy measurements of the cooling ramp of cycle 1 + positions outside the test set); smallest k reaching the best AUC: k = 5 on all 4 folds.

## Why the CNN AUC on D16 is below 0.5

Median logit per group (5 seeds; > 0 means damaged): healthy c1 (train) -8.7; healthy c2 (test) -8.5; D16 (test) -9.5; D04, D12, D24 (train) +8.8.
The network clearly classifies D16 as healthy: it recognizes the positions it has seen, not damage in general. The AUC below 0.5 only reflects small differences within the healthy class.
